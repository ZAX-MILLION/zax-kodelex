# Legal documents (plain-language overview)

These files protect you and set rules for users. They are **templates**, not a lawyer’s advice for your country.

| Document | What it does for you |
|----------|----------------------|
| Terms of Service | Users agree to rules; limits your liability; requires users to cover (indemnify) you if they break the law |
| Acceptable Use | Clearly bans piracy, malware, and other illegal uses |
| Disclaimer | States you don’t approve misuse and aren’t responsible for how others deploy the code |
| DMCA / Copyright | Explains how rights holders request removals; separates your site from other people’s self-hosted copies |
| Privacy / Cookies | Explains data collection (needed for a real public site) |
| LICENSE + NOTICE | On GitHub: code is proprietary; no permission for illegal use; as-is, no warranty |

## What you should still do

1. Put your real contact email in legal pages if it changes (currently `contact@zaxmillion.com`).
2. If you earn money or store user data in the EU/UK/California, have a lawyer review Privacy + Terms.
3. Only host manga/comics you own or have permission to use.
4. Answer DMCA / copyright emails promptly and remove infringing uploads.
