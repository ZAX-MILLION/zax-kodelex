# ZAX Seamless v2.0.0 — Release notes (draft)

**Release title:** ZAX Seamless v2.0.0  
**Tag (after merge):** `v2.0.0`  
**Status:** Draft only — do **not** publish until PR #2 is approved, merged, `main` build passes, and the live demo is verified.

## Highlights

- New seamless editorial homepage
- Responsive redesign across phone, tablet, and desktop
- Demo Role Lab (guest → member → paid → buyer → uploader → admin)
- Readable original demo chapters (sample SVGs)
- Local demo blog (no database required in demo mode)
- Improved webtoon reader (safe-area, scale clamp, navigation)
- Environment separation (demo / staging / production)
- Payment catalogue hardening and demo checkout isolation
- SEO noindex policy for private and demo routes
- Accessibility improvements (contrast, landmarks, focus, touch targets)
- Performance-minded demo builds for GitHub Pages
- Security posture docs and operator runbooks

## Upgrade notes

- Demo builds must set `VITE_APP_ENV=demo` (or `VITE_DEMO_MODE=true`) with payments/admin disabled.
- Production still requires your own Supabase project, migrations, storage, and edge functions.
- PayPal: sandbox architecture is in place; live capture needs merchant credentials and a successful live transaction before claiming “payments live.”
- GitHub Pages currently serves the project path `/zax-kodelex/` until an ADMIN root-site migration is completed.

## Known external setup (not automated)

- PayPal merchant / sandbox credentials
- Custom domain / root Pages migration
